# odin-recipes
This project is a simple recipe website that showcases a collection of quick and easy dinner recipes, perfect for busy weeknights. The site is built with basic HTML and CSS.

Recipes
The website features the following recipes:
One Pan Orecchiette Pasta: A simple and affordable one-pan pasta dish.
Blackened Ranch Pan-Fried Chicken Thighs: A quick and flavorful chicken dish cooked in a cast-iron skillet.
Simple Tortellini Soup: A comforting and easy soup recipe.
Easiest Sheet Pan Tacos: A convenient and delicious taco recipe made on a single sheet pan.
Quick Chicken Piccata: A classic chicken dish that can be prepared in under 30 minutes.
